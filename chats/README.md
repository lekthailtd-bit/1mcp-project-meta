# Chat Continuity

Use this directory only when a substantive ChatGPT/Codex conversation benefits from durable continuity beyond `CURRENT_STATE.md`.

## Folder naming

`YYYY-MM-DD-short-topic/`

Do not introduce global chat numbering unless a real coordination need appears.

## Preferred files

- `tldr.md` — purpose, current/final state, important findings, source branch/commits, validation, blockers, next action.
- `handover.md` — only when a successor needs explicit continuation instructions.

Do not copy full conversation transcripts into Git. Update `CURRENT_STATE.md` when project-wide current state changes.

See `TEMPLATE.md`.
